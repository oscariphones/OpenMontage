# REGLAS_ZONACHEF — Skill de producción automatizada de contenido comercial

Guía estricta para la producción automatizada de videos comerciales de ZonaChef.

1. EXTRACCIÓN DE ASSETS (FUENTE OFICIAL): Para cada video, debes buscar el producto asignado en la página oficial [https://zonachef.com.mx/](https://zonachef.com.mx/). Extrae las especificaciones reales, capacidades y beneficios para redactar el guion. Descarga las imágenes de producto directamente de la web (o utiliza herramientas de terminal para bajarlas) y guárdalas en la carpeta del proyecto para usarlas en la animación. Nunca inventes especificaciones técnicas.
2. IDENTIDAD VISUAL (SaaS Motion Design): Estrictamente prohibido usar estilo oscuro, personajes de plastilina o cuadrículas neón de otros proyectos. El estilo debe ser corporativo, limpio y técnico. Fondos: Blancos o grises muy claros. Colores de acento: Rojo corporativo y Negro.
3. COMPOSICIÓN VISUAL (Object-Centric): El protagonista visual es la foto real del equipo descargada de la web. Alrededor de esta imagen se animarán elementos de interfaz (UI) limpios: etiquetas de specs técnicos, calculadoras de ROI, indicadores de rendimiento y viñetas dinámicas.
4. VOZ Y TONO: El guion debe ser narrado por un 'Consultor Gastronómico'. Tono profesional, directo y orientado a B2B, hablándole a dueños de negocios sobre rentabilidad, eficiencia operativa y durabilidad.
5. RENDER Y EXPORTACIÓN (MODO LOCAL): El pipeline de trabajo termina exactamente cuando se genera el MP4. ESTÁ ESTRICTAMENTE PROHIBIDO ejecutar scripts de publicación o subida automática a YouTube. Guarda el video final directamente en la carpeta renders/zonachef/ y detén el proceso notificando el éxito.
